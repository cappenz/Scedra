# Scedra

Scedra is an iOS app that turns spoken, typed, or photographed appointments into calendar events, then helps with travel time and conflicts.

Open `Scedra.xcodeproj` in Xcode and run on an iPhone or the simulator. The app asks for calendar, microphone, and location access when those features are used.

Do not commit secrets, `.env` files, signing certificates, or local Xcode user data.
